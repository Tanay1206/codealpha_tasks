# CodeAlpha Data Analytics Tasks

## About This Repository
This repository contains the projects and tasks completed during my Data Analytics Internship at CodeAlpha. The focus of this internship is to gain hands-on experience in data extraction, cleaning, statistical analysis, and visualization.

## Tasks Overview

### Task 1: Web Scraping
* **Objective:** Extract structured data from a public web page to create a custom dataset.
* **Target:** Scraped the "Top Anime" leaderboard from MyAnimeList.
* **Output:** `MyAnimeList_TopAnime.csv` (contains Rank, Title, and Score).
* **Code:** `task1_web_scraper.py`

### Task 2: Exploratory Data Analysis (EDA) - *In Progress*
* **Objective:** Explore data structure, identify trends, and analyze patterns using Python.
* **Target:** Analyzing the custom MyAnimeList dataset created in Task 1.
* **Code:** `task2_eda.ipynb`
