# CodeAlpha Data Analytics Tasks

## About This Repository
This repository contains the projects and tasks completed during my Data Analytics Internship at CodeAlpha. The focus of this internship is to gain hands-on experience in data extraction, cleaning, statistical analysis, and visualization.

## Tasks Overview

### Task 1: Web Scraping
* **Objective:** Extract structured data from a public web page to create a custom dataset.
* **Target:** Scraped the "Top Anime" leaderboard from MyAnimeList.
* **Output:** `MyAnimeList_TopAnime.csv` (contains Rank, Title, and Score).
* **Code:** `task1_web_scraper.py`

### Task 2: Exploratory Data Analysis (EDA)
* **Objective:** Explore data structure, identify trends, and analyze patterns using Python.
* **Target:** Cleaned and analyzed the custom MyAnimeList dataset created in Task 1.
* **Code:** `task2_eda.ipynb`

### Task 3: Data Visualization
* **Objective:** Create insightful visual representations of the data to uncover correlations and trends.
* **Target:** Built interactive and static charts to visualize the anime dataset.
* **Code:** `task3_dataviz.ipynb`

### Task 4: Sentiment Analysis
* **Objective:** Process and analyze text data to determine underlying sentiment and categorize feedback.
* **Target:** Applied natural language processing techniques to evaluate text-based data.
* **Code:** `task4_sentiment.ipynb`

## Technologies & Libraries Used
* **Language:** Python
* **Libraries:** requests, BeautifulSoup4, pandas, matplotlib, seaborn
* **Tools:** Jupyter Notebooks, VS Code, Git
